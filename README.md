# Masal Bahçesi

Türk halk masallarından seçilmiş sekiz masalı bir araya getiren tek sayfalık web derlemesi. Programlamaya Giriş dersi vize ödevi olarak hazırlanmıştır.

## Ne yapar?

- Masalları ada veya içeriğe göre arama
- Türe göre filtreleme
- Favorilere ekleme (aynı tarayıcıda saklanır)
- Okuma alanında yazı boyutunu ayarlama
- Telefon ve bilgisayara uyumlu düzen

CSS ve JavaScript HTML dosyasının içindedir. Sayfa internet bağlantısı olmadan da çalışır.

## Nasıl açılır?

`masal-bahcesi.html` dosyasını indirip çift tıklayarak tarayıcıda açın.
